# Fuentes pixeladas (opcional)

La aplicación busca archivos `.ttf` en esta carpeta al arrancar. Para tener la interfaz con letra
pixelada, descargue de Google Fonts (licencia SIL Open Font License, de uso libre) y copie aquí:

| Archivo | Uso en la aplicación |
|---------|----------------------|
| `PressStart2P-Regular.ttf` (familia **Press Start 2P**) | Títulos y botones |
| `VT323-Regular.ttf` (familia **VT323**) | Texto, casillas y gráficas |

También sirve **Silkscreen** en lugar de cualquiera de las dos. Si no hay fuentes aquí, la
aplicación usa Consolas o Courier New. Los títulos grandes y la animación del motor se ven
pixelados igual, porque usan una fuente de mapa de bits propia (`pixel.py`).
